# Jitsi Meet (local Docker)

Runs in the same Compose project as the API (`student-research`).

## Quick start

```bash
npm run docker:jitsi:setup
npm run docker:jitsi:reset    # required once after changing .env
docker compose up -d jitsi-web jitsi-prosody jitsi-jicofo jitsi-jvb
```

Open **https://localhost:8443** (accept the self-signed certificate warning).

Set in the API environment:

```env
JITSI_BASE_URL=https://localhost:8443
```

New defense/meeting bookings will use that base URL. Re-schedule existing rows if links still point at the old URL.

## Why HTTPS (8443), not HTTP (8000)?

Jitsi’s config generator only strips a `https://` prefix from `PUBLIC_URL`. Using `http://localhost:8000` produces broken URLs like `wss://http://localhost:8000/...`, which causes **“You have been disconnected”**. HTTPS on 8443 avoids that and works better with browser WebRTC.

Do **not** open meetings on `http://localhost:8000` — that port may 301 to `https://localhost/...` (wrong port). Always use **https://localhost:8443**.

| jitsi-jvb | student-research-jitsi-jvb | 10000/udp (media) |

## Troubleshooting disconnects

1. **Reset config** after any `.env` change: `npm run docker:jitsi:reset` then restart Jitsi containers.
2. In the browser, open DevTools → Network and confirm WebSocket goes to `wss://localhost:8443/xmpp-websocket`, not `wss://http://...` or port 8000.
3. **LAN devices**: set `JVB_ADVERTISE_IPS` and `PUBLIC_URL` to your host LAN IP in `docker/jitsi/.env`, set `JITSI_BASE_URL` to match, reset config, restart.
4. Allow **UDP 10000** through the firewall for video/audio.

## Branding

Archivum’s boxy UI is applied via `docker/jitsi/branding/`:

- `custom-config.js` / `custom-interface_config.js` — synced into `cfg/web/` by `npm run docker:jitsi:setup` (appended to Jitsi config on container start)
- `body.html` + `archivum-jitsi.css` — mounted into the Jitsi web image for layout/CSS overrides

After changing branding files, restart Jitsi web:

```bash
docker compose restart jitsi-web
```

Keep branding in sync with `research-pipeline-web/lib/meetings/jitsiTheme.ts` (embed API overrides). The web app renders its own Teams-style control bar and hides Jitsi’s native toolbar via config + `archivum-jitsi.css`.

## Files

- `docker/jitsi/branding/` — Archivum Jitsi theme (tracked in git)
